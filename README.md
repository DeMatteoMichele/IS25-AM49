# IS25-AM49

Repository for the Software Engineering project at PoliMI
This project is a Java-based implementation of the table game Galaxy Tracker, developed at Politecnico di Milano. The team members are Andrea Compagnoni, Davis Crippa, Michele De Matteo e Daniele Confalonieri.

The implementation features both a command-line interface (CLI) and a JavaFX graphical user interface.
